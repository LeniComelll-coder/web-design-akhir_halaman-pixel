# Pixel Page - Web Design Final Project 🎨

Selamat datang di repositori **Pixel Page**! Proyek ini awalnya adalah tugas akhir untuk kelas duck sc, namun dalam prosesnya, saya menjadikannya sebagai tempat bereksperimen dan "bermain" dengan struktur serta elemen desain web.

## 🚀 Tentang Proyek
Proyek ini merupakan implementasi halaman web statis yang dirancang untuk memenuhi kriteria tugas akhir. Fokus utamanya adalah pada penyusunan tata letak (layout) dan navigasi antar halaman yang sederhana namun fungsional.

### Fitur & Halaman:
* **Halaman Utama (`index.html`):** Landing page atau beranda utama dari situs.
* **Menu Halaman (`menu1.html`):** Halaman tambahan untuk navigasi konten atau fitur lainnya.
* **Integrasi Visual:** Penggunaan elemen grafis untuk mendukung estetika halaman.

### Tech Stack:
* **Bahasa Utama:** HTML5
* **Styling:** CSS (Internal/External sesuai struktur proyek)
* **Aset:** Gambar/Ikon pendukung

## 🛠️ Cara Menjalankan Proyek
Kamu bisa langsung melihat hasil desainnya dengan cara:

1.  **Clone repositori:**
    ```bash
    git clone [https://github.com/LeniComelll-coder/web-design-akhir_halaman-pixel.git](https://github.com/LeniComelll-coder/web-design-akhir_halaman-pixel.git)
    ```
2.  Buka folder proyek di file explorer kamu.
3.  Klik dua kali pada file `index.html` untuk membukanya di browser pilihanmu.
